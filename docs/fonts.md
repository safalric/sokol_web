# Písma webu

Aktualizováno 10. září 2026. Uživatel výslovně potvrdil oprávnění jednoty používat sokolská písma.

## Sokol Tyrš

Oficiální plný nadpisový řez, autor Vojtěch Říha, vizuální styl ČOS. Soubor `public/fonts/SokolTyrs-Regular.woff2` pochází přímo z [oficiálního webu Sokola](https://www.sokol.eu/assets/fonts/SokolTyrs-Regular.woff2); odkaz je uveden v jeho [CSS](https://www.sokol.eu/assets/css/sokol.css?v=1.12).

Použití: nadpisy a typografická část názvu jednoty. CSS rodina `Sokol Tyrs`, řez Regular, `font-display: swap`. Písmo není nahrazené podobným volným fontem. Oficiální přehled písem uvádí [školení ČOS](https://sokol.eu/assets/download/EG2p3bd5xy.pdf).

Manuál a kompletní fontový balíček poskytuje [Sokol Brandcloud](https://prosokoly.sokol.eu/graficky-manual-brandcoud), přístup zprostředkuje ČOS/jednota. Soubor je určen pouze pro tento sokolský web; oprávnění k dalšímu šíření jako samostatného fontového balíčku se tím neuděluje. Schválení licence pro zveřejnění webu uchová vedení v předávací dokumentaci.

## Work Sans

Běžný text, ovládání a formuláře. Lokální WOFF2 varianty Latin a Latin Extended zahrnují české znaky; proměnná váha 400–900. Zdroj: [Google Fonts](https://fonts.google.com/specimen/Work+Sans), licence OFL v `public/fonts/WorkSans-OFL.txt`.

Žádný externí fontový server se při prohlížení webu nekontaktuje. Při selhání souboru zůstává čitelný systémový fallback. Sokol Fügner (obrysový řez) záměrně není použitý pro běžné malé texty kvůli čitelnosti.
